## Featured Projects

- **[ImageJ-nuclei-counter](https://github.com/BRR-uni/ImageJ-nuclei-counter)** — FIJI/ImageJ plugins to automate segmentation and counting of nuclei from DAPI-stained confocal z-stack images, with semi-automated and fully automated versions.
- **[OptoGeneLaser](https://github.com/BRR-uni/OptoGeneLaser)** — Android app + Arduino code to control light stimulation frequency (on/off duration, cycles, rest periods) for optogenetics experiments via Bluetooth.
- **[ImageJ_z_stack_plugins](https://github.com/BRR-uni/ImageJ_z_stack_plugins)** — FIJI/ImageJ plugins to automate z-projection (max intensity) and channel merging/enhancement for confocal microscopy images (CZI format).
- **[Plots-and-Statistical-tests](https://github.com/BRR-uni/Plots-and-Statistical-tests)** — Python/Jupyter scripts to generate time-series plots, correlation jointplots, and run statistical tests (normality, variance, group differences) from Excel data.
- **[SBB_Chamber](https://github.com/BRR-uni/SBB_Chamber)** — 3D-printable 4-well chamber insert to improve Sudan Black B immunostaining on tissue slices, reducing sample loss and antibody usage.
- **[Aromatic_Cycle_Grouper](https://github.com/BRR-uni/Aromatic_Cycle_Grouper)** — Python script to identify aromatic cycles in molecules, group adjacent rings, and export results for molecular docking workflows.
- **[ORM-Timer](https://github.com/BRR-uni/ORM-Timer)** — Android dual-timer app for manual scoring of Object Recognition Memory tests in mice, with press-and-hold operation and countdown features.
